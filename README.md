# 🏠 House Price Prediction Using Machine Learning

## 📌 Project Overview
This project predicts house prices using Python and Machine Learning. It uses the Linear Regression algorithm to estimate house prices based on features such as area, number of bedrooms, bathrooms, floors, and age of the house.

## 🎯 Objectives
- Predict house prices using Machine Learning.
- Understand the Linear Regression algorithm.
- Analyze housing data using Python.
- Evaluate model performance.
- Visualize actual and predicted house prices.

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📊 Dataset Description
The dataset contains the following features:

| Feature | Description |
|---|---|
| Area | House area in square feet |
| Bedrooms | Number of bedrooms |
| Bathrooms | Number of bathrooms |
| Floors | Number of floors |
| Age | Age of the house in years |
| Price | House price in rupees |

## 🤖 Machine Learning Algorithm
**Linear Regression**

Linear Regression learns the relationship between house features and prices to estimate the price of a new house.

## ⚙️ Project Workflow
1. Import the required Python libraries.
2. Generate the sample housing dataset.
3. Save the dataset as a CSV file.
4. Split the data into training and testing sets.
5. Train the Linear Regression model.
6. Evaluate the model using MAE and R² score.
7. Visualize actual and predicted prices.
8. Predict the price of a new house.

## 🚀 How to Run the Project
1. Open Google Colab.
2. Open `House_Price_Prediction.ipynb`.
3. Run all code cells in order.
4. View the dataset, evaluation results, graph, and predicted house price.

## 📈 Model Evaluation
The project uses:
- **Mean Absolute Error (MAE):** Measures the average prediction error.
- **R² Score:** Measures how well the model explains variations in house prices.

## 📁 Project Files
- `House_Price_Prediction.ipynb` — Python code and model implementation.
- `house_prices.csv` — Sample housing dataset.
